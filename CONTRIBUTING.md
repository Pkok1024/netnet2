# Contributing to Net Speed Indicator

Thank you for your interest in contributing to **Net Speed Indicator**!

---

## How to Contribute

1. **Fork and clone** the repository:
   ```bash
   git clone https://github.com/Pkok1024/net-speed.git
   ```
2. **Open the project** in Android Studio or build via Gradle.
3. **Follow the code style**:
   - Use Kotlin and Jetpack Compose for UI development.
   - Adhere to Material 3 design guidelines.
   - Maintain battery-friendly and I/O-optimized patterns.
4. **Submit a Pull Request** with a clear explanation of changes and improvements.
